# `composition/` — node-graph core

The parametric graph itself: model + types + hydrate/mutate (`composition-graph*`),
graph → source emit (`composition-emit`, `-profile`), bake orchestration
(`composition-bake`), canvas auto-layout, `composition-tree` (TreeNode), plus
`engine-hash` (engine-source digest / cache-bust) and `param-keys` (ordered meta.params).
